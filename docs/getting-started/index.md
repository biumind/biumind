# 什么是 BiuMind

BiuMind 是一个一体化 AI 工作平台：写文档、跑 Agent、写代码、做笔记这些原本分散在多个工具里的工作，被收进同一个工作台，并且**数据互通**——文档、网页剪藏、对话里值得留下的内容都沉淀进同一个知识库，由 AI 连成知识图谱，供所有场景复用。

部署方式有两种：

- **云端版（注册即用）**：在官网 [biumind.ai](https://biumind.ai) 注册账号即可使用，适合个人和小团队。
- **自托管**：一行命令拉起完整服务栈，数据全程留在自己的服务器，适合企业和数据敏感场景。

两种方式客户端体验一致，详见[快速开始](quickstart.md)。

## 六大模块

### 知识中枢

写文档、管知识的地方（后端为 `brain` 服务，客户端对应 `features/wiki`、`features/notes`、`features/memory`、`features/search`）：

- **Wiki 文档**：基于块编辑器写作，支持页面版本历史、修订对比与合并。
- **知识图谱**：以图谱视图查看页面之间的关联，可按条件过滤。
- **AI 记忆**：AI 记住你说过的话和偏好，在对话、编码、消息接入等场景自动带上上下文。
- **全局搜索**：跨文档的语义搜索，一句话找回之前的内容。
- **外部内容接入**：浏览器剪藏扩展一键把网页存成 Wiki 来源；剪藏或导入的内容可经 AI 摄取流程自动整理成多篇 Wiki 页面。

### 编码工作台

在图形界面里派 AI 工程师干活（客户端对应 `features/code`，后端为 `runtime` 服务，与 `biu` CLI 共享同一 Agent 内核）：

- 多个 AI 任务**并行**执行，每个任务在自己的工作区里改代码。
- 内置 Git 面板（分支 / 提交 / 历史）、终端、文件树。
- AI **改文件、跑命令前先征求你的确认**，权限策略可控，还可以挂 Hooks 做审计。
- 支持 Skills 扩展 Agent 能力。

### 创作（AIGC）

一句话把灵感变成成品（客户端对应 `features/creation`，后端为 `aigc` 服务 + 异步 worker）：

- 文生图、文生视频。
- 爆款内容拆解，帮你分析一条内容为什么火。
- 角色设定管理、生成任务画廊与"我的作品"集中沉淀。

### 云端工位

换设备、换入口，工作不中断：

- 会话、任务、记忆存在云端服务器（`runtime` + `realtime` 服务），桌面、手机、命令行登录同一账号随时接续。
- 支持自带模型 Key（BYOK）：你的 API Key 由平台加密保管，模型调用统一经模型网关（`model-relay`）转发，计费口径一致。

### 消息接入

把 AI 接进你已有的沟通渠道（后端为 `channels` 服务）：

- 已实现飞书、Telegram、Slack、Discord、邮件渠道 driver（按部署环境配置启用）。
- 收到消息自动回复，并自动召回你的知识库与 AI 记忆作为回答上下文，回答不跑偏。

### 应用中心

开箱即用的专业 AI 助手（客户端对应 `features/apps`，后端为 `app_center` 服务）：

- 内置参考应用：**RSS**（订阅信息源，AI 生成摘要 / 日报 / 周报 / 转写）、**翻译**、**任务**。
- 应用可安装、可升级，也可以开发自己的 BiuApp 装进应用中心。

## 多端覆盖

一个账号，多个入口随时切换，CLI 与图形客户端共享同一内核、会话互通：

| 入口 | 说明 |
|------|------|
| 桌面端（主力工作端） | macOS（Apple Silicon）安装包已发布；Windows / Linux 安装包发布中，可先用 Web 版 |
| 移动端 | Android 可直接下载 APK 安装；iOS 版即将上线 |
| Web 版 | 浏览器打开即可用，无需安装 |
| 浏览器扩展 | Chrome / Edge / Brave 剪藏扩展，看到的内容一键存进知识库 |
| 命令行 | `biu` CLI，终端内对话、跑 Agent、操作知识库 |
| 跨端小程序 | uni-app 小程序（微信 / 支付宝 / 抖音 / 百度 / QQ / 快手 / 京东 / 飞书 / H5），建设中 |

各端的具体安装方式见[下载与安装](download.md)。
