# BiuMind Documentation

BiuMind is an all-in-one AI work platform: write documents, run agents, code, and take notes in a single workspace, with data that flows across modules and gets connected into a knowledge graph by AI.

It ships in two ways: a cloud SaaS (sign up and go) and self-hosting (private deployment).

## The six modules

| Module | In one line | Guide |
|---|---|---|
| Knowledge Hub | Wiki documents, knowledge graph, global search, external sources, AI research and review | [Knowledge Hub & Notes](guide/knowledge.md) |
| Chat | Model selection, slash commands, approval cards, cross-session search, save to Wiki | [Chat](guide/chat.md) |
| Coding Workbench | Git, terminal, file tree, parallel tasks, Skills / Hooks | [Coding Workbench](guide/code.md) |
| Creation (AIGC) | Text-to-image, text-to-video, viral content teardown, inspiration and gallery | [Creation](guide/creation.md) |
| Cloud Workspace | Cloud sessions and memory, picked up on any device | Coming soon |

| App Center | Install built-in and community apps, or build your own BiuApp | [App Center](guide/apps.md) |

On top of these sits one cross-cutting capability: **Skills** — reusable, signable agent skills (see [Using Skills](guide/skills.md) and [Building Skills](developers/skills.md)).
