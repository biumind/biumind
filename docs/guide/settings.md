# 账号与设置用户指南

设置是 BiuMind 的账户与偏好中枢：登录账号、接入你自己的模型 API Key、签发第三方工具用的长期令牌、管理多端登录设备、调整外观与各模块默认行为、查看用量统计、处理会员订阅与版本更新，都在这里完成。

## 认识设置页

点击左侧边栏底部的用户区打开「设置」。桌面端是「左导航 + 右内容」双栏布局；手机端自动变为两级页面——先看分类列表，点进条目后进入全屏详情，返回键回到列表。

左侧导航按分组组织：

| 分组 | 条目 |
|---|---|
| 通用 | 数据统计、外观、搜索、我的分享、文档处理 |
| 智能体 | 凭证管理、模型服务、已登录设备、API Tokens、活动、编码工作台（桌面端）、聊天平台 |
| 订阅与计费 | 会员中心、订单历史、兑换码、邀请奖励 |
| 设备 | 我的设备 |
| 系统 | 关于 |
| 账户 | 退出登录 |

部分条目（快捷键、网络代理、数据存储等）标记为「soon」，是尚未开放的占位，当前不可点击。

> [!NOTE]
> 「编码工作台」条目仅在桌面端显示；「已登录设备」管理的是**登录会话**，「我的设备」管理的是**配对的 biu CLI 机器**，两者用途不同，见[多端登录与设备管理](#多端登录与设备管理)。

## 登录与账号

### 首次登录（凭证管理）

首次使用时，先在「智能体 → 凭证管理」完成服务地址与账号配置：

1. **服务地址**：填你的 BiuMind 服务器地址（正式站点或自托管站点地址，本地开发环境为 `http://localhost:8088`）。
2. **邮箱** 与 **密码**：你的账号凭据。
3. 点击**登录**。

登录成功后会话历史在多设备间自动同步；页面底部会显示访问令牌的到期时间（令牌会自动续期，无需手动处理）。

### 注册与邮箱验证

在凭证管理页点击**注册**，填写邮箱和密码提交后，系统会发送 6 位验证码到你的邮箱（若站点未配置邮件服务，请联系管理员从服务日志获取验证码）。随后到登录页输入验证码完成邮箱验证——未完成验证的账号无法登录。

### 退出登录

两种入口：设置页「账户 → 退出登录」，或侧边栏底部用户区。确认后会清除本地缓存（知识库、创作、订阅相关缓存），编码项目保留；跳回登录页。

> [!WARNING]
> 退出登录只影响当前设备，其他设备的登录态不受影响。要让某台设备立即下线，请用[已登录设备](#已登录设备登录会话)里的撤销功能。

## 模型服务：配置你自己的 API Key（BYOK）

「智能体 → 模型服务」让你接入自己的模型服务商 API Key（Bring Your Own Key）。配置后，相应模型的调用走你自己的 Key，跳过平台扣费。

页面左侧是服务商卡片列表，右侧（宽屏）是选中服务商的配置详情；窄屏点击卡片进入配置页。凭据分两种出口，用卡片上的角标区分：

| 角标 | 出口 | 适用场景 |
|---|---|---|
| 云端 | 经 BiuMind 云端转发到服务商 | 跨设备可用，任何端登录同一账号都能用 |
| 桌面 | 从本机桌面端直连上游地址 | 服务端连不到的上游，例如公司内网代理、本机自建网关 |

### 支持的服务商

Anthropic Claude、OpenAI GPT、DeepSeek、字节跳动豆包、阿里灵积 DashScope、火山方舟（Doubao 视觉）、Google Gemini、Azure OpenAI、Kimi（Moonshot）、阿里通义千问、百川，以及「自定义」（OpenAI 兼容 / Anthropic / Google 协议的任意上游，如自建网关）。

每张卡片显示凭据状态：

- 未配置（云端服务商会显示「未配置 — 录入后跳过平台扣费」提示）；
- 已配置且校验通过：卡片尾部绿色对勾，副标题显示 Key 末四位与上游地址；
- 已配置但校验失败：红色感叹号。

### 配置云端凭据

1. 点左侧对应服务商卡片。
2. 填 **API Key**（标准服务商只需这一项）。
3. （可选）填**备注**，方便多把 Key 时区分。
4. 点**保存**。编辑已有凭据时 Key 框留空表示保留原密钥不变。

### 配置自定义服务商

选择「自定义」后，除 API Key 外还需填：

- **Base URL**：上游地址，如 `https://new-api.example.com`；
- **协议**：OpenAI 兼容（new-api / vLLM / DeepSeek 等网关）、Anthropic 或 Google；
- **所用模型**：声明这把 Key 覆盖哪些模型，逗号分隔。支持前缀通配，例如 `glm-*`（所有 glm 开头的模型）或 `glm-4.5,glm-4`（精确列举）。

> [!WARNING]
> 模型匹配只支持「整串通配 `*`」或「前缀通配（如 `glm-*`）」，不支持中间通配——`glm-*-mini` 会被当成精确模型名，永远不会命中。

调用时系统按模型名匹配这些声明，命中即路由到你的 Key，而不是走平台计费。

### 配置本机直连凭据

1. 点列表底部的**添加本机直连凭据**。
2. **上游地址（Base URL）**为必填，例如 `https://内网代理` 或服务商官方地址。
3. 选协议、填所用模型（规则同上，必填）、填 API Key。
4. 保存后卡片带「桌面」角标，聊天分流由本机桌面端直连该上游执行。

> [!NOTE]
> 本机直连凭据目前仅支持「自定义」服务商。如果你看到旧版本创建的标准服务商直连凭据显示「历史遗留的死凭据」红色提示，请删除后按自定义重新创建。

### 测试连接

配置页左下角**测试**按钮发起连通性检测：

- 云端凭据：由服务端代测，返回 `valid` / `invalid` / `network` 等结果；
- 本机直连凭据：从本机直接发一次真实请求，成功显示「连通正常（延迟 ms）· 模型名」。若所填模型是通配（如 `glm-*`），会先拉取上游 `/models` 列表解析出第一个匹配的具体模型再测。

### 删除凭据

配置页右下角**撤销**（云端）或**删除**（本机直连）按钮，确认后立即生效，不可恢复，需要时须重新录入。

## API Tokens（给第三方工具用的长期令牌）

「智能体 → API Tokens」用于签发长期有效的 Bearer Token（PAT），给 MCP server、CI 脚本、自动化程序等不方便使用登录会话的场景。完整说明见 [API 与第三方集成](../developers/api.md)。

### 创建 Token

1. 点右上角**创建**。
2. 填**名称**（如 `claude-desktop` / `ci-deploy`）。
3. 勾选**权限**：`read`（读取知识库 / 搜索 / 列表）、`write`（创建 / 编辑 / 合并 page）。
4. 拖动滑块选择**有效期**：7 至 365 天，默认 365 天。
5. 点**创建**，弹窗显示完整 Token 明文，格式为 `bm_<8位前缀>_<JWT>`。点**复制**保存，再点**我已保存**关闭。

> [!WARNING]
> Secret 只在创建时显示这一次，服务端不再保存明文，关闭弹窗后无法再查看。请立即复制保存到安全的地方。

使用时把整个 `bm_...` 字符串原样放进请求头：

```text
Authorization: Bearer bm_xxxxxxxx_eyJhbGciOi...
```

### 撤销 Token

列表中每个 Token 卡片显示名称、脱敏前缀、权限、上次使用时间与到期日。点**撤销**并确认即可。

> [!WARNING]
> 撤销确认框会提示：当前部署不强制撤销，已签发的 Token 在到期前仍可能有效。若怀疑泄露，请缩短有效期重新签发并替换所有使用方。

## 多端登录与设备管理

同一个账号可以同时登录桌面端、移动端、Web 端，数据自动同步。每个端登录后都会在账号下注册一个会话。

### 已登录设备（登录会话）

「智能体 → 已登录设备」列出所有登录会话：

- 每张卡片显示设备名称（如 `macOS · MacBook-Pro`、`Web on macOS`）、设备类型图标、最近活跃时间与 IP、授权有效期与到期日；
- 当前使用的设备带紫色「当前设备」标记，排在最前；
- 点**撤销**让对应设备立即下线，该设备需重新登录；撤销当前设备等于在本机退出登录；
- 存在其他设备时，页面底部出现「一键踢出」：除当前设备外全部注销。

### 我的设备（biu CLI 配对）

「设备 → 我的设备」管理通过 `biu pair` 配对的远程机器（例如家里跑着 biu CLI 的 Mac）：

1. 在目标机器上运行：

```bash
biu pair
```

2. 机器会显示一个 8 位配对码，回到客户端点右下角**批准新设备**，输入配对码确认。
3. 批准后该设备自动获得 device token 并出现在列表中，显示在线状态（在线 / 离线 / 最后活跃时间）。

每台设备可以单独设置**工具权限**：只读、读写限定目录、全权；也可以随时**吊销**——吊销后该设备的 token 立即失效，需重新配对。

### 命令行（CLI）登录

biu CLI 用 `biu auth login` 走 OAuth 流程登录同一账号（支持 `--manual` 手动模式），详见 [biu CLI 入门](../cli/getting-started.md)。

> [!TIP]
> 「已登录设备」管的是各个客户端 App / 浏览器的登录态；「我的设备」管的是 `biu pair` 配对出来的远程执行机器。前者撤销后要重新输密码登录，后者吊销后要重新配对。

## 外观

「通用 → 外观」分四段设置，全部即时生效，无需重启：

| 设置项 | 内容 |
|---|---|
| 界面语言 | 跟随系统 / 中文 / English |
| 颜色主题 | 18 套主题色板（推荐区在前），双色圆点预览主色与强调色，点选即切换 |
| 字体大小 | 小 / 中 / 大，影响字号、间距与列表密度，下方卡片实时预览效果 |
| 模式 | 跟随系统 / 浅色 / 深色 |

## 聊天平台

「智能体 → 聊天平台」配置新对话的出厂行为（详细概念见[对话用户指南](chat.md)）：

| 设置项 | 内容 |
|---|---|
| 默认对话模式 | 新对话默认选中 Chat / Agent / Task 中的哪一个（出厂为 Agent） |
| 默认模型（chat 模式） | 新会话默认使用的模型；选「BiuMind 默认（不指定）」则跟随平台配置 |
| 语音朗读 | 朗读用的语音来源：默认「设备本地语音（离线、免费）」；选云端语音模型后可进一步填音色 ID，朗读走高质量云端合成，失败时自动回落本地语音 |
| 自动从首句 prompt 起标题 | 开启后新会话根据第一条消息自动命名；关闭则侧边栏保留「新对话」占位，等你手动改名 |

## 编码工作台

「智能体 → 编码工作台」（仅桌面端）配置 AI 编程 agent 的可执行文件路径与默认工作目录（使用概念见[编码用户指南](code.md)）：

- **任务隔离（worktree）**开关：开启时每个任务在独立 git worktree + 分支（`biu/<agent>-<id>`）中执行，多任务并行互不干扰；关闭则所有任务共享工作目录，可能互相覆盖文件。切换即时保存。
- **Working dir**：任务执行的目录，agent 在此读写文件。
- **biu / Claude / Codex** 三个可执行文件路径：留空走 PATH 自动查找；特殊安装位置填绝对路径。每行带 **Test** 按钮，执行 `<路径> --version` 验证并显示版本或错误。
- **自动检测路径与版本**：经桌面守护进程扫描 PATH 及常见安装目录（nvm / brew / `.local/bin` 等），自动填充**空白**字段并汇总各 agent 版本。守护进程未连接时该按钮禁用（逐字段 Test 仍可用）。
- 页面下方展示**当前生效的 PATH**（从登录 shell 解析），便于排查「终端里能找到、App 里找不到」的问题。
- **恢复默认**清空所有路径输入框；**保存**写入配置。

## 文档处理

「通用 → 文档处理」决定导入知识库的文档（PDF / DOCX / XLSX / PPTX / EPUB / HTML / MD / TXT）在哪里解析：

| 选项 | 行为 |
|---|---|
| 自动（默认） | 小文件本机解析（免费，桌面 ≤50MB / 移动端 ≤10MB），大文件自动走云端 |
| 优先本机 | 尽量在本机解析（免费），仅超大文件（>200MB / 移动端 >80MB）走云端 |
| 优先云端 | 全部上传云端解析，按页扣积分 |

本机解析免费；云端解析按页花积分；扫描件 OCR 与音视频转写仅支持云端。不支持本机解析的平台（Windows / Linux）会禁用「优先本机」并提示始终使用云端。

页面下方是**Wiki 生成模型**：上传文档自动生成 Wiki 页时使用的模型。该偏好保存在账号下、跨端同步；默认「跟随平台默认」，自选模型按你的用量计费（优先使用你配置的 API Key）。

## 搜索

「通用 → 搜索」目前只有一项开关：**在统一搜索中包含笔记**。开启后全局搜索页的结果会附带匹配的笔记（标题 + 摘要）；关闭则只搜知识库内容。不影响笔记模块内部的笔记搜索。

## 我的分享

「通用 → 我的分享」集中管理你发出过的所有笔记分享链接（分享本身在笔记编辑器工具栏或列表右键菜单发起）。每行显示笔记标题、状态角标（生效中 / 已停用 / 已过期 / 已上限）、有效期、访问次数（如 `访问 3 / 10 次`）与是否设密码。

可执行的操作：

| 操作 | 效果 |
|---|---|
| 复制链接 | 仅生效中可用，复制当前分享地址 |
| 停止分享 | 链接立即无法访问，之后可恢复（链接地址不变） |
| 恢复分享 | 已停用的分享以原链接恢复 |
| 重置链接 | 生成新 token，旧链接立即作废，之前发出去的链接全部失效 |

## 数据统计

「通用 → 数据统计」是账户级、跨设备的用量与活跃统计，分「活跃概览」和「用量」两部分。

**活跃概览**：

- 四张指标卡：话题数、消息数、累计 Token、使用模型，各带月环比（较上月的增减百分比）；
- 过去一年活跃度热力图（类似贡献格子），右上角显示「活跃 N 天」「连续 N 天」；
- 两个排行：模型使用率（各模型消息数）、话题内容量（消息最多的会话）。

**用量**（按月查看，可前后翻月）：

- 三张卡：今日花费（积分）、本月花费（积分 + 调用次数）、活跃模型数；
- 按天柱状图，可在**积分**与 **Token** 之间切换；
- 模型花费分布排行；
- 调用明细表：每条调用显示模型、输入 / 输出 Token、TPS、花费（积分）、时间，分页浏览。

## 会员与积分

### 会员中心

入口有三处：侧边栏底部的积分徽章、设置页「订阅与计费 → 会员中心」、用户头像菜单。页面自上而下：

- **当前方案卡**：套餐名、订阅状态、周期截止日；积分余额（区分永久积分与时效积分）；Chat 月度配额与 AIGC 月度配额的已用进度条；
- **月付 / 年付切换**（年付带折扣角标）；
- **选择套餐**：各套餐卡片显示价格（年付折算到月）、权益清单（每月积分、Hub RPM / TPM、每日沙盒任务数、Brain 项目数），当前套餐标「当前」，其他套餐按高低显示「升级」/「降级」；
- **单次充值积分包**：一次性购买的积分（不影响订阅与月度积分），时效包带有效天数角标（如 `30d`），点击进入支付页。

### 升级、降级与取消

- **升级**：选更高套餐后弹确认框，展示按比例补差明细（旧方案剩余抵扣、新方案补差、本次需支付），确认后进入支付；
- **降级**：确认后于周期末生效；
- **取消订阅**：当前方案卡上的「取消订阅」提供两种方式——「周期结束时停止」（继续服务至周期末，不退款）或「立即停止 + 按比例退款」；
- 已取消的订阅可点**恢复订阅**。

### 支付

支付页先选支付方式，再点**立即支付**：

| 方式 | 说明 |
|---|---|
| 微信支付（扫码） | 展示二维码内容与订单号，用微信扫一扫支付 |
| 微信支付（H5） | 跳转微信 H5 支付 |
| 支付宝（网页 / 手机） | 打开浏览器跳转支付宝完成支付 |
| 国际信用卡（Stripe） | 海外信用卡通道 |

支付完成后回到客户端，积分通常在支付回调确认后到账；可回到会员中心刷新查看。

### 订单历史

「订阅与计费 → 订单历史」列出全部订单：金额、支付渠道（微信支付 / 支付宝 / Stripe / Apple IAP / Google Play）、订单类型、创建时间、渠道单号（可复制），状态角标区分已支付（绿）/ 待支付（蓝）/ 已退款（橙）/ 失败与已取消（红）。

### 兑换码

「订阅与计费 → 兑换码」输入券码点**兑换**，支持四类券：立减 / 折扣 / 积分礼包 / 试用延长。常见错误会直接提示原因（兑换码无效、已过期、已停用、已使用过、不适用当前套餐、币种不匹配、已达使用上限）。兑换成功后订阅与订单数据自动刷新。

### 邀请奖励

「订阅与计费 → 邀请奖励」展示你的专属邀请码与邀请链接（可一键复制或通过系统分享），以及邀请统计（总邀请 / 已奖励 / 待生效 / 已撤销）。

奖励规则：

- 被邀请人首次完成 1 笔有效订阅，双方各得 500 积分；
- 同 IP / 设备指纹 24 小时内邀请超阈值视为刷量，不发奖励；
- 被邀请人退款或异常时，已发奖励将被回收。

### 套餐对比表

客户端内置一张套餐对比表，横向对比各档的月费、年费、月度积分、Hub RPM / TPM、每日沙盒任务数与 Brain 项目数，每列底部可直接选择套餐。<!-- TODO: 待确认：当前版本该对比页（`/membership/compare`）已注册路由但未发现界面内入口，会员中心内的套餐卡片为主要对比视图。 -->

## 版本更新

- **更新横幅**：检测到新版本时，应用顶部出现提示条，显示版本号与更新说明摘要，点**前往下载**跳转官网下载页；点关闭仅本次会话内不再提醒，重启后会重新检测。
- **手动检查**：「系统 → 关于」页自动检查更新（60 秒内重复进入不重复请求），显示「发现新版本」「已是最新版本」「检查失败」三种状态；点**重新检查**强制重新查询，发现新版本时提示条带「前往下载」按钮。
- **获取开发版**：「关于」页的开关（标注「未签名 · 可能不稳定 · 数据请先备份」）。开启后改为检查每夜构建通道，检测到新构建时提示「发现新开发版 #N」，下载直链按平台自动匹配（Apple Silicon / Windows / Linux AppImage / Android APK）。

「关于」页同时显示当前版本号与构建号（版本 + 构建时间戳）。

## 活动

「智能体 → 活动」是账号的操作事件流：按时间倒序显示最近操作（如 PAT 创建 / 撤销，未来还会包括 page 编辑、技能安装等），滚动到底部自动加载更早记录，右上角可手动刷新。
