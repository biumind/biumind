# 对话用户指南

对话是 BiuMind 的 AI 聊天工作台：左侧是会话列表，右侧是聊天区。你可以随时切换模型、附带图片、引用技能，把有价值的内容收藏、存进 Wiki 或导出备份。智能体模式下，助手还能调用工具、向你提问，由你决定放行哪些操作。

## 认识界面

桌面端是「会话列表 + 聊天区」双栏布局；窄屏（手机）自动变为两级页面——先看列表，点进会话后全屏聊天，左上角返回键回到列表。

会话列表顶部一排图标按钮，从左到右：

| 按钮 | 作用 |
|---|---|
| 命令面板 | 打开全局命令面板（Cmd/Ctrl+K） |
| 收藏的消息 | 跨会话查看所有 ⭐ 收藏的消息 |
| 搜索全部对话 | 跨会话搜索历史消息（Cmd/Ctrl+Shift+F） |
| 导入对话 JSON | 从备份文件恢复会话 |
| 批量管理 | 进入会话多选模式（批量删除） |
| 新建对话 | 新建一个空白会话 |

列表下方还有一个「过滤对话…」输入框，按标题实时过滤当前列表（只过滤未归档会话）。

未选中任何会话时，右侧是欢迎页：按时段显示问候语、使用统计、六张起点提示卡、已安装的技能、最近用过的模型和最近会话。手机上没有欢迎页，改为在会话列表为空时直接显示问候 + 四张起点卡。

## 开始一段对话

### 新建会话

三种方式任选：

- 点列表顶部的 **+** 按钮（或按 Cmd/Ctrl+N），直接按默认偏好建一个空白会话；
- 在欢迎页点任意**起点卡**，自动新建会话并把提示词填进输入框；
- 按 Cmd/Ctrl+K 打开命令面板，选「新建对话」。

新会话默认使用你在偏好里配置的默认模型；没有配置或该模型已下线时，使用平台默认模型。

### 发送与停止

- **Enter** 发送，**Shift+Enter** 换行；手机软键盘上回车是换行，发送走输入框右下角的圆形按钮。
- 生成过程中，输入框右下角变成**停止按钮**；顶部标题栏也会出现一个停止按钮，方便你翻看历史时随时中断。停止后消息尾部会标注「已停止」。
- 生成中标题旁会显示「生成中」及实时速率（如 `· 25 t/s`）。

### 输入历史与草稿

- 输入框为空时按 **↑** 可翻阅本会话发送过的历史消息（↓ 往回翻），选中即回填。
- 每个会话的输入草稿**自动保存**（停止输入约半秒后落盘），切走再切回来文字还在；发送成功后草稿自动清空。
- 想看所有会话没发完的半成品：命令面板（Cmd/Ctrl+K）→「查看草稿（半成品）」。列表里每行显示会话标题、草稿摘要和字数，点击跳回对应会话，右侧按钮可丢弃单条草稿。

## 选择模型

### 按会话切换模型

模型是**会话级**设置：每个会话可以各用各的模型，互不影响。

点击输入框底部的**模型 chip**（显示当前模型名），弹出模型选择对话框：

- 顶部搜索框直接按名称 / 标识过滤；
- 模型按提供方分组列出，每行显示模型名、价格标签（实际计费价）和上下文窗口大小（如 200K）；平台默认模型带「默认」徽标；
- 分组标题右侧的齿轮：平台池模型跳转会员中心，自有 Key（BYOK）模型跳转设置的 API Keys 页管理密钥。

对话框内只列出「当前确实可用」的模型——要么走平台池，要么你已经配置了有效的自有 Key。列表为空时会提示前往配置密钥。

快捷键 Cmd/Ctrl+Shift+M 可在会话中直接唤出模型选择对话框。

> [!TIP]
> 在欢迎页的「最近用过的模型」一排 chip 上点击，可把它设为**全局默认模型**——新会话都会用它开局。

### 费用预估与积分

- 输入超过 20 个字符后，发送按钮旁会出现**费用预估 chip**：平台计费显示「约 N-M 积分」，走自有 Key 时显示绿色「0 积分 · BYOK」。估价在停止输入约 0.6 秒后自动刷新，失败时静默隐藏，不打断输入。
- chip 旁边还有一个小计数：「N 字 · ~M tokens」（token 数为本地估算，仅供参考）。
- **积分不足**时，系统会弹出「余额不足」对话框，显示本次所需积分与当前余额，可选「立即充值」（跳转会员中心）或「录入 BYOK」（跳转设置，配置自己的上游 Key 后平台不再扣费）。
- 模型不可用（停用 / 不存在 / 无渠道）时，会话顶部会出现红色错误横幅，并附「重新选择模型」一键修复按钮；套餐档位不够时则提供「升级会员」入口。

### 上下文窗口

会话顶部（搜索栏下方）有一条细进度条，显示当前会话**累计消耗的上下文**：进度条 + 「已用 / 总量 · 百分比」。占用超过 60% 变橙色，超过 85% 变红色。鼠标悬停可看具体数字。

> [!TIP]
> 上下文快满时，模型会开始「遗忘」最早的内容。此时可以新建会话，或把重要结论先存入 Wiki / 收藏，再继续。

## 输入器的进阶用法

### 斜杠命令与技能

在输入框开头输入 `/`，会弹出命令菜单，包含内置命令和已安装的技能两段：

| 命令 | 作用 |
|---|---|
| `/new` | 新建对话 |
| `/clear` | 清空输入框 |
| `/note` | 把最近一条完成的回复存为笔记 |
| `/help` | 查看可用命令列表 |

菜单里选中**技能**会插入 `/<技能标识> `，接着输入你的问题即可。↑↓ 选择、Enter 触发、Esc 清空；`/` 后面跟了空格或参数时菜单自动让位。快捷键 Cmd/Ctrl+/ 可在输入框为空时直接唤出菜单。

### @ 引用技能

除了 `/`，还可以在消息里用 `@技能标识` 引用技能。欢迎页的技能一排 chip 点击后会把 `@<标识> ` 自动填进输入框，你只需接着写具体要求。

> [!NOTE]
> 输入框本身没有 `@` 自动补全弹窗；`@` 引用靠欢迎页的技能 chip 或手动输入标识符完成。

### 联网搜索

输入框左下角的**地球图标**是「联网搜索」一次性开关：开启后图标高亮，发送时会在你的消息前自动附加一条「优先使用网络搜索」的提示，本轮发送后开关自动关闭。生成过程中不可切换。

### 对话 / 智能模式

输入框底部的**模式 chip** 可在两种模式间切换：

| 模式 | 说明 |
|---|---|
| 对话 | 纯模型问答，不调用工具 |
| 智能 | 通过本机守护进程调用工具（读写文件、执行命令等） |

切到「智能」时如果检测不到在线的守护进程，会提示「无 daemon 在线」，无法切换。切换成功后，输入框下方会多出两个 chip：

- **工作目录**：点开选择本机目录作为助手的工作范围（选中的目录会自动加入信任范围）；已设置时显示目录名，**长按 chip 可清空**。
- **工具调用批准**：三档可选——「自动批准」（所有工具调用直接放行）、「白名单」、「手动批准」（每次都询问）。

### System Prompt 与模板

通过会话右上角 **⋮ 菜单 → 对话设置**打开设置面板，可编辑该会话的 System Prompt（会作为系统消息附加到每次请求），并查看模式、模型、创建 / 更新时间。

常用的 System Prompt 可以存成**模板**反复使用：

- 命令面板 →「管理 System Prompt 模板」：新建 / 编辑 / 删除模板（名称 + 全文）。
- 命令面板 →「应用 system prompt 模板」（需先选中会话）：一键把模板套到当前会话。
- 对话设置面板里也有「从模板选」按钮，直接把模板填入编辑框。

## 发送图片附件

附件目前**仅支持图片**（png / jpg / jpeg / webp / gif / heic），单张上限 10MB，发送前会自动压缩到模型友好尺寸（超限或格式不符会弹提示）。

添加方式：

- 点输入框左下角的 **+** 按钮选择图片文件；
- 桌面端直接把图片**拖进**输入框，或 **Cmd/Ctrl+V 粘贴**剪贴板里的图片；
- 手机上点 + 后三选一：拍照 / 从相册选择 / 选择文件。

附件以缩略 chip 的形式排在输入框上方，显示文件名、大小，点右上角 ✕ 可移除，随下一条消息一起发送。

> [!WARNING]
> 当前模型不支持图片输入时，+ 按钮会置灰并提示切换到支持视觉的模型。

## 管理你的会话

### 单个会话操作

鼠标悬停会话条目，右侧出现 **⋯** 按钮；也可以直接**右键**（手机**长按**）条目弹出同一菜单：

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 置顶 / 取消置顶 | Cmd/Ctrl+P | 置顶的会话固定排在列表顶部「置顶」分组 |
| 重命名 | F2 | 修改会话标题 |
| 归档 | Cmd/Ctrl+E | 移出列表，进入归档管理 |
| 导出 JSON | Cmd/Ctrl+Shift+E | 把该会话导出为 JSON 备份文件 |
| 删除 | Cmd/Ctrl+Backspace | 二次确认后删除（不可恢复） |

手机上还可以在会话条目上**左滑**快速归档。

### 归档管理

列表底部有「已归档 N」入口（数量为 0 时不显示）。归档页里每条会话可「解归档」放回列表，或「永久删除」（二次确认，不可恢复）。

### 收藏 / 草稿 / 跨会话搜索

- **收藏的消息**：点助手消息底部的 ⭐ 收藏。列表顶部星形按钮打开收藏夹，跨会话查看所有收藏，点击任意一条直接跳回原会话并定位到该消息。
- **跨会话搜索**：搜索框输入关键词（防抖即时查询），结果按会话分组，显示角色、命中高亮片段和时间；点击跳回对应会话并定位。
- **会话内搜索**：在会话里按 Cmd/Ctrl+F，顶部出现搜索栏，Enter 跳下一条、Shift+Enter 上一条、Esc 关闭，右侧显示「当前 / 总数」。

### 导出与导入

- **单会话导出**：会话菜单「导出 JSON」。
- **全部导出**：命令面板 →「导出全部对话」，生成一份包含归档会话的完整 JSON 备份。
- **导入**：列表顶部上传图标，选择 JSON 文件即可。导入会自动识别单会话备份和全量备份两种格式。

### 命令面板

Cmd/Ctrl+K 打开，集中了以上所有入口（新建、搜索、收藏、草稿、归档、批量管理、导出全部、模板、设置、快捷键面板），还能模糊匹配快速**切换到任意最近会话**。

## 处理消息

### 助手消息操作

每条完成的助手消息底部有一排操作图标（手机上精简为高频项 + ⋮ 菜单收纳低频项）：

| 操作 | 说明 |
|---|---|
| 😊 表情反应 | 弹出常用表情网格，「更多表情」进全量选择器；已选表情以 chip 显示，再点一次取消 |
| ⭐ 收藏 | 收藏 / 取消收藏该消息（进入收藏夹） |
| 复制 | 复制全文 |
| 复制为 markdown 引用 | 复制成 `>` 引用格式（超长自动截断为前 6 行） |
| 重新生成 | 以同一提问重新生成回答 |
| 引用回复 | 把该消息转成引用块注入输入框（仅桌面） |
| 翻译 | 在 Google 翻译中打开（仅桌面） |
| 朗读 / 停止朗读 | 系统语音朗读，自动识别语言 |
| 存为 Wiki 页 | 见下文 |
| 分享为图片 | 见下文 |
| 删除 | 二次确认后删除该条（不可恢复） |

消息末尾还有一个小型 token 统计（如 `↑1.2k ↓356`），鼠标悬停消息时右上角会浮出包含高频操作的迷你工具条。长按消息头像另有「查看原始结构 / 复制消息 ID / 切换收藏 / 删除」等高级操作。

### 用户消息操作

鼠标悬停自己发出的消息可：复制、**编辑**（内联编辑器，保存即改写该条）、重新生成（以该消息为提问，截断其后重发）、删除。

### 多选消息

会话右上角 ⋮ 菜单 →「多选消息」（或命令面板），消息前出现复选框，底部浮出操作条：**复制**（合并为 markdown）、**翻译**（Google 翻译打开，超长自动截断到 4500 字）、**导出 MD**（生成带模型与消息数的 Markdown 文件）、**删除**、全选、取消。

### 长回答导航

- 含 3 个及以上标题的长回答，顶部出现可折叠**大纲**（「大纲 · N 条」），点开展示层级标题列表。
- 会话超过 6 条消息时，右侧出现**导览条**：每条消息一格（用户灰色、助手紫色、失败红色），点击直接跳到该消息。
- 每条完成的助手消息下方有三个**追问建议** chip（再展开讲讲 / 举个例子 / 更简洁），点击即把对应的追问填入输入框。

### 存入 Wiki 与笔记

- **存为 Wiki 页**：自动剥离思考过程等噪声，取首行做默认标题，弹窗中可改标题、选择目标项目，保存后提示条可一键打开新页面。
- **存为笔记**：输入 `/note` 把最近一条完成的回复存成笔记，提示条可跳转笔记列表。

### 分享为图片

「分享为图片」把单条消息渲染成一张带品牌样式的卡片（含 BiuMind 标识、模型名、时间），可**保存 PNG** 到本地，桌面端还可**复制图片**到剪贴板直接粘贴使用。

> [!NOTE]
> 分享卡会把 markdown 格式剥离为纯文本展示，代码块和表格在图片中以纯文本形式呈现。

## 与智能体协作：审批与表单

### 工具审批卡

智能模式下（批准模式非「自动批准」时），助手每次要执行工具调用，输入框上方会浮出一张审批卡：显示工具名称、调用理由和入参预览（超过 4 行折叠，点击展开）。三个选择：

| 按钮 | 效果 |
|---|---|
| 允许 | 放行本次调用 |
| 始终允许 | 放行本次，并把本会话的批准档位升为「自动批准」，后续不再询问 |
| 拒绝 | 跳过本次调用，助手会换路径继续 |

### 提问表单卡

助手需要你拍板时会浮出一张**表单卡**：问题、可选的选项 chip（支持单选 / 多选 / 自由文本输入）。你可以「提交」所选答案，也可以「跳过」（让助手自行选择默认）或「取消」。作答后卡片变为只读状态记录你的选择，超时未答也会标注。

## 键盘快捷键

按 **Shift+?**（输入框未聚焦时）可随时查看快捷键面板：

| 快捷键 | 作用 |
|---|---|
| Enter | 发送 |
| Shift+Enter | 换行 |
| ↑ / ↓ | 翻阅输入历史 |
| `/` | 斜杠命令菜单 |
| Cmd/Ctrl+K | 命令面板 |
| Cmd/Ctrl+N | 新建对话 |
| Cmd/Ctrl+P | 置顶 / 取消置顶当前会话 |
| Cmd/Ctrl+Shift+F | 搜索全部对话 |
| Cmd/Ctrl+F | 在当前对话中搜索 |
| Cmd/Ctrl+Shift+M | 切换模型 |
| F2 | 重命名当前会话 |
| Cmd/Ctrl+E | 归档当前会话 |
| Cmd/Ctrl+Shift+E | 导出当前会话 JSON |
| Cmd/Ctrl+Backspace | 删除当前会话 |
| Shift+? | 快捷键面板 |

> [!NOTE]
> macOS 上修饰键为 ⌘，Windows / Linux 上为 Ctrl；手机端不显示快捷键提示。技能的安装与管理参见 [Skills 用户指南](skills.md)。
