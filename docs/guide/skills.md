# Skills 用户指南

Skill（技能）是给 AI 助手扩展能力的指令包：一段写好步骤和要点的说明书，需要时再配上脚本、参考资料等资源。装好之后，助手在合适的场景会自动调用对应技能——比如「写周报」「生成架构图」「按团队规范起 Git 提交信息」这类重复性套路，都可以沉淀成一个技能，不必每次重新教。

技能管理入口在客户端的「技能管理」页。使用前需先登录，否则页面会提示「请先登录后管理云端技能」。

## 浏览与筛选

技能列表是单列卡片流，每行显示：头像（图标或首字母，颜色按技能标识自动分配）、名称、来源徽章、一行简介、状态文字和右侧的「⋯」菜单。内置技能固定排在最前，其余按更新时间倒序。

顶部的筛选标签（带数量）：

| 筛选 | 含义 |
|---|---|
| 全部 | 所有技能 |
| 内置 | BiuMind 官方自带 |
| 组织 | 团队里其他成员共享给你的 |
| 我的 | 你自己创建或导入的 |
| 市场 | 从技能商店 / URL 安装的第三方技能 |
| 待审 | 已提交、等待批准上线的草稿 |

状态有四种：**已启用**（助手可用）、**待审核**（草稿或更新提案）、**已停用**（手动停用）、**已暂停**（被平台暂停）。

## 查看技能详情

点击技能行打开详情面板——桌面端是右侧抽屉（不丢失列表上下文），窄屏自动变成全屏。分两个标签页：

**概览**：

- **该技能能访问**：权限的人话版本，例如「可读你的知识库」「可在沙盒里运行代码」「可访问外部网络」；没有任何额外权限时显示「无额外权限（只调用模型本身）」
- **详情**：作者、版本、许可、仓库链接、更新时间，以及**调用次数**和**最后调用时间**——用得多的技能一目了然
- **第三方提示**：非内置技能会标注「该技能由第三方提供，BiuMind 不保证其行为符合预期，请评估后使用」
- **自动附加路径**（如有）：技能会在哪些工作目录下自动挂载
- **基于现有版本的修改**（如有）：如果这是一次对已有技能的更新提案，会展示新旧版本摘要
- **操作按钮**：待审核技能显示「批准」「驳回」（驳回需填写原因）；非内置技能显示「删除」（需二次确认，不可恢复）

**技能功能**：

左侧是该技能的文件树——`SKILL.md`（技能说明书正文）加 `scripts/`（脚本）、`references/`（参考资料）、`assets/`（素材）等资源文件；点击任一文件在右侧查看内容。资源文件会显示大小、类型和校验值。部分大文件存储在云端对象存储，详情页暂只显示元信息。

## 安装技能

点右上角「添加」打开安装对话框，三种方式对应顶部的三段切换：

| 方式 | 用法 | 适合 |
|---|---|---|
| URL | 粘贴一个 `https://…/SKILL.md` 地址，服务端通过 HTTPS 拉取 | 从技能商店或别人分享的链接安装（**「技能商店」按钮直达此页签**） |
| Zip | 选择本地 `.biuskill` / `.zip` 技能包上传（≤ 8 MB） | 离线拿到的技能包 |
| 手写 | 直接填标识符（kebab-case）、名称、描述和正文，当场创建一个属于自己的技能 | 把自己的常用套路沉淀成技能 |

> [!TIP]
> 手写技能的正文里可以用 `$ARGS` 占位符：调用时传入的参数会替换进去，一个技能就能吃下变化的输入。

安装失败会内联显示原因（包超限、地址拉取失败等），改完直接重试。

## 启用、停用与置顶

技能行右侧的「⋯」菜单按当前状态提供不同操作：

- **已启用**：「置顶到默认助手」、「停用」
- **已停用**：「启用」
- **待审核**：「批准」（批准后自动对默认助手启用）、「驳回」
- 所有非内置技能：「删除」

启停与置顶作用于你的**默认助手**：停用后助手不再自动加载该技能，但技能本体仍在列表里，随时可以重新启用；内置技能不可删除，但同样可以停用。

## 云端同步与团队协作

技能全部存在云端账号下，换设备登录即有同一份技能列表，无需手动迁移。多端协作时列表实时联动：

- 你在另一台设备安装、启停或删除技能，本机列表自动刷新
- 团队场景下，有人提交了新技能或更新提案、管理员批准或驳回了提案、有人把技能共享给组织——相关成员都会看到一条实时提示（如「skill-creator · approved」）
- 提交的技能提案（包括对现有技能的更新）会以「待审核」状态出现在列表中，走批准 / 驳回流程后才正式生效，避免未经验证的指令直接进入所有人的助手

> [!WARNING]
> 第三方技能本质上是给助手的指令，可能要求访问你的知识库、文件甚至沙盒执行。安装前先在详情页看清「该技能能访问」清单，按需安装。

## 想自己写技能？

本文只覆盖使用侧：浏览、安装、启停、审批。技能的文件格式（`SKILL.md` 的 frontmatter 与正文规范）、权限声明、打包 `.biuskill` 的命令、以及提审-审批的完整生命周期，见开发者文档 [Skills 开发与使用](../developers/skills.md)。
