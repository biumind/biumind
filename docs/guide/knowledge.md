# 知识中枢指南

本指南介绍 BiuMind 的知识中枢——「知识库」与「笔记」两个模块的日常使用，是 [快速开始](../getting-started/index.md) 之后的进阶篇；聊天、应用中心等其他模块见同目录下的其他指南。

知识中枢分两层：

- **知识库**：以「项目」为单位的结构化知识库。把 PDF、Word、网页、Markdown 等资料接进来，系统自动解析成互相链接的 Wiki 页面，并提供图谱、搜索、AI 对话、AI 调研、AI 整理等能力。
- **笔记**：轻量随手的个人笔记，笔记本 + 标签 + 待办组织，支持分享、回收站，写好的笔记可以一键「转入知识库」沉淀为 Wiki 页面。

两者数据互通：网页剪藏、聊天内容可以进知识库，笔记可以升级为知识库页面，全部内容都能在全局搜索中检索到。

## 知识库

### 建一个项目

1. 点击桌面客户端左侧边栏的「知识库」，进入项目列表页。
2. 第一个项目还没有时，会看到欢迎页和 5 张起手模板卡片；之后也可以随时点右上角「新建工作区」按钮或网格末尾的「新建项目」卡片。
3. 选择一个模板（或直接新建空白项目）：

| 模板 | 适合场景 |
|---|---|
| 研究 | 深度研究：假设追踪 + 方法论 + 综述 + 知识图谱 |
| 阅读 | 读书笔记：人物 / 主题 / 情节线 / 章节记录 |
| 个人成长 | 目标 / 习惯 / 反思 / 日记，链接成自我知识网 |
| 商务团队 | 团队知识库：会议纪要 / 决策 / 项目 / 干系人 |
| 通用 | 从空白开始，自由组织内容 |

4. 在弹出的「新建项目」对话框里输入项目名，点「创建」。选了模板时，系统会自动为项目生成结构性的起手页面（「通用」模板不生成）。

进入项目后，左侧是功能栏，包含这些入口：

| 入口 | 用途 |
|---|---|
| 页面 | 浏览、阅读、编辑本项目的所有 Wiki 页面（快捷键 ⌘P 按页面名跳页） |
| 源文件 | 上传 / 管理 PDF、Markdown、URL 等来源 |
| 搜索 | 项目内三路搜索（关键词 / 语义 / 图谱） |
| 图谱 | 页面关系网络可视化 |
| 对话 | 基于本项目的 AI 对话 |
| 研究 | Deep Research 调研任务 |
| 审查 | AI 审阅队列（重复、矛盾、过时等问题） |
| 镜像 | 导出整个项目为 markdown 包 |

功能栏底部还有「工作区」（回项目列表）、「LLM 设置」「反馈」「全局设置」。窗口底部的状态栏显示项目名、连接状态和「活动」入口（点开是后台任务面板），以及「⌘K 命令面板」提示。

> [!TIP]
> 在知识库内按 **⌘K**（Windows 上 Ctrl+K）打开命令面板，可以键盘直达上面所有入口；按 **⌘P** 则进入「按页面名跳页」模式，输入几个字就能跳到任意页面。手机上这些入口收进顶行的列表按钮和页面右上角的 ⋮ 菜单。

### 把资料接进项目（源文件）

**上传文件或网页**

1. 在项目里打开左侧「源文件」页。
2. 点右上角「上传」按钮，弹出「导入数据源」对话框，有三种方式：
   - **单文件**：选一个 PDF / DOCX / XLSX / PPTX / EPUB / Markdown / HTML / TXT 文档；
   - **多文件**：一次选多个文件，全部加入后台队列；
   - **URL**：粘贴一个 `https://…` 网页地址（HTML / PDF / Markdown），系统抓取后入库。
3. 选好的条目会列在对话框下方，点「加入队列」后立即返回，解析在后台进行。进度可以在底部状态栏的「活动」面板里查看（支持取消、失败重试）。

解析完成后，资料会被 LLM 拆解成多个 Wiki 页面，自动出现在「页面」列表里。

> [!NOTE]
> 文档解析的位置在「设置 → 通用 → 文档处理」里配置：自动（默认，小文件本机免费解析、大文件云端）、优先云端（按页消耗积分）等。不支持本机解析的平台一律走云端。

**管理源文件**

「源文件」页的列表每行显示文件名、状态徽标（排队中 / 解析中 / 已就绪 / 失败）、大小和路径，右侧两个按钮：

- ⚡ **解析**：手动触发一次解析任务（会跳到解析进度页，实时显示 排队中 / 解析中 / 部分完成 / 已完成 / 失败 等状态和事件日志）；
- 🗑 **删除**：删除该源文件（页面引用关系不会自动清除，重复项会进入审查队列处理）。

> [!WARNING]
> 目前客户端没有「新建空白页面」按钮——项目里的页面主要由源文件解析、AI 调研、对话存档产生。页面列表的空态文案虽提到"新建页面"，但该入口尚未实现。

### 阅读与编辑页面

**页面列表**：左侧「页面」栏按页面的「类型」（frontmatter 中的 type 字段）分组展示，组头可展开 / 收起，上方的过滤框按标题或路径即时过滤。点击任一页面，右侧打开阅读视图。

**阅读与编辑切换**：页面标题右侧有「阅读 / 编辑」分段开关。内容为空的页面默认直接进入编辑模式。编辑器是所见即所得的 Markdown 编辑器，改动自动保存，无需手动点保存。正文支持表格、任务列表、数学公式、代码块（mermaid 代码块会渲染成图）。

**双链**：编辑时输入 `[[` 会弹出本项目页面名的自动补全，选中即插入 `[[页面名]]` 链接；阅读时点击双链直接跳转到目标页面。

**页面周边信息**（标题与正文之间）：

- **元信息条**：类型、标签、描述、来源（origin，如 web-clip / deep-research）、关联来源等 chips；点铅笔图标打开编辑表单，可修改标题、描述、类型、创建日期、来源、标签，以及自定义键值；
- **相关页面**：与当前页面最相关的一组页面 chips（悬停可见关联原因，如直接 wikilink、共享邻居、类型亲和），点击跳转；
- **反向链接**：哪些页面引用了当前页面，卡片带上下文摘要，点击跳转。

**大纲**：有两个以上标题的页面，右侧自动出现大纲面板，编辑模式下点击大纲条目可滚动定位。

**标题行工具条**（手机收进 ⋮ 菜单）：

| 按钮 | 作用 |
|---|---|
| 页内搜索 | 在项目全部页面内容中搜索，命中显示标题 + 高亮摘要，回车跳转 |
| 历史记录 | 该页面「谁在什么时候做了什么」的事件时间线 |
| 版本历史 | 内容快照列表，见下文 |
| 维护 (agent) | 让 AI 整理本项目，见「让 AI 整理知识库」 |

**版本历史**：弹层左侧是版本列表，右侧预览该版本的标题和正文。两个动作：

- **恢复到此版本**：当前页面会被该版本覆盖（服务端会自动把覆盖前的状态备份成一个恢复点，不会丢数据）；
- **另存为副本**：把该版本存成一个新页面。

**划词 AI**：在编辑模式下选中一段文字，选区下方会出现浮动工具条，两个模式：

- **改写**：输入指令（例：更简洁 / 翻译成英文 / 加示例），AI 给出对比预览（词级差异高亮），可「重生成」或「接受」写回正文；
- **提问**：针对选中内容提问（例：这段和 X 概念啥关系？），AI 回答并附引用。

### 知识图谱

打开左侧「图谱」进入项目关系图谱：每个节点是一个页面，节点之间的边表示关联（双链与语义相关性），整体用力导向布局自动排布。可以用鼠标 / 手势缩放和平移，点击节点跳转到对应页面。

图谱是系统自动生成和维护的，不需要手工连线。顶部工具栏从左到右：

| 控件 | 作用 |
|---|---|
| 搜索框 | 按节点标题搜索并高亮 |
| 过滤 | 面板：隐藏结构页（index / overview / log 等导航页）、隐藏孤立页、按页面类型显示、按连接数区间筛选 |
| 着色切换 | 节点颜色按「聚类」或「页面类型」两种模式切换 |
| 配色 | 更换图谱配色主题 |
| 洞察 | 打开「图谱洞察」面板，见下 |
| 刷新 | 重新拉取图谱数据 |
| 重建关系 | 触发服务端重算页面关联（含语义相关性） |

> [!TIP]
> 「图谱洞察」面板会给出两类提示：**意外连接**（跨聚类 / 跨类型的强关联，可能是你没注意到的联系）和**知识缺口**（孤立页、稀疏聚类、缺少关联的桥节点）。每条可以点 ⌖ 图标在画布上定位高亮，也可以逐条「不再显示」。知识缺口卡片上还有「研究」按钮，一键对该缺口发起 Deep Research。

### 搜索

**项目内搜索**（左侧「搜索」）：输入关键词，300ms 防抖后自动搜索，结果合并三路命中并标注来源——「关键词」（BM25 文本匹配）、「语义」（向量相似）、「图谱」（通过相关页扩展发现），每条带分数和摘要，点击跳转页面。

**全局搜索**（主侧边栏「搜索」）：跨模块统一搜索，输入框提示「搜索 BiuMind 知识库与网络…」。结果按分区展示：

- **笔记**：命中的笔记条目；
- **页面**：知识库页面命中，带 BM25 / VEC / GRAPH / WEB 来源徽章（融合了联网搜索结果）；
- **图片**：命中的图片网格，点开大图后可「跳到来源页面」。

### 项目内 AI 对话

两种进入方式：左侧「对话」入口，或在「页面」里不选中任何页面——右侧默认就是本项目对话面板。对话基于本项目的知识内容回答。

聊出有价值的内容后，可以在助手消息的操作菜单里选择**存为 Wiki 页**：填写页面标题、选择存入的知识库项目，消息内容即成为项目里的一页。

### AI 调研（Deep Research）

1. 打开左侧「研究」，点右上角「新研究」。
2. 填写「主题」（必填，例：transformers 的注意力机制）和「辅助查询」（可选，每行一条，用来引导搜索方向）。
3. 点「开始研究」。任务卡片会显示状态流转：排队中 → 搜索中 → 综合中 → 落页中 → 完成（或失败）。
4. 完成后点「打开生成页」：AI 综合多来源写成的研究报告落地为一个 Wiki 页面，正文带 `[[双链]]` 交叉引用，元信息里 origin 标记为 deep-research，与其他页面一起进入图谱和搜索。

> [!TIP]
> 还有两个「一键研究」入口：审查队列里的问题项可以点「研究」直接调研（研究完成后该审阅项自动标记为已处理）；图谱洞察的知识缺口卡也可以直接发起研究。

### 让 AI 整理知识库

**自动维护（agent）**

1. 打开任意页面，点标题行工具条的「维护 (agent)」。
2. 在弹出的「维护 (agent)」对话框里填写**维护指令**（例：整理这个项目的知识，补全缺失页，合并明显重复），选择**强度**（快速 4 轮 / 标准 8 轮 / 深度 12 轮）和**模型**。
3. 点「开始维护」。对话框切换为运行视图：上方是「工具调用」步骤列表（实时显示 agent 读了哪些页面、做了什么操作），下方流式输出 agent 的工作说明。期间可随时「停止」。
4. 运行结束后展示总结和**改动面板**：agent 做的每一处修改（新建 / 编辑 / 合并页面）逐条列出，可点开看「变更对比」，可逐条「撤销」。
5. 点左下角「历史运行」可回看以前的维护记录，同样支持撤销当时的改动。

> [!NOTE]
> 维护 agent 的所有写操作都会自动快照到页面版本历史，任何改动都可以在「版本历史」里回滚，不用担心 AI 改坏内容。

**审查队列**

打开左侧「审查」（标题「审阅队列」），这里是后台工作进程发现的可整理点，按类型标签筛选：dedup（重复页面）、lint（规则问题）、sweep（陈旧 / 孤立页面）等。右上角「扫描」菜单可手动触发：

- **结构扫描**：空标题 / 孤儿页 / 重复标题等规则检查，即时完成；
- **语义扫描**：LLM 判定矛盾 / 过时等语义问题，后台处理。

每个问题卡片显示类型徽章、描述、涉及的页面（点击深链直达），以及一组处理动作：

| 动作 | 含义 |
|---|---|
| 研究 | 发起 Deep Research 调研此问题，完成后自动标记已处理 |
| 合并… | （重复页）选择保留哪一侧为「主页面」，另一侧内容并入后软删除 |
| 建查询页 | （矛盾类）把矛盾点整理成一个待查证的新页面 |
| 已处理 | 我已经手动修好了 |
| 忽略 | 这不是问题，不再提示 |

### 导出项目

左侧「镜像」页可以把整个项目导出为 zip（Obsidian 风格的 markdown 包，正文与双链格式完整保留）：点右上角「导出为 zip」，完成后弹窗显示导出页数，可一键复制路径。导出文件可在本地用任意 markdown 工具打开。

## 笔记

### 界面与组织

点击主侧边栏「笔记」进入。桌面是三栏：左边「笔记本」，中间笔记列表，右边编辑器；手机上是列表与全屏编辑两个页面切换。

- **新建笔记**：中栏头部「+」按钮；在某个笔记本或待办视图下新建时，会自动归入当前笔记本 / 直接建为待办。
- **新建笔记本**：左栏头部的新建文件夹按钮。笔记本支持多级目录：右键（手机长按）笔记本弹出菜单——新建子目录 / 移动到… / 升到根级 / 删除笔记本（删除前会二次确认；本内笔记进回收站，子笔记本上移一层，笔记本本身不可恢复）。
- **智能视图**：全部笔记 / 未归档 / 待办 / 已分享（带活跃分享数徽标）。
- **标签**：左栏底部标签区，点 + 新建标签；给笔记打标签后按标签筛选。
- **搜索**：中栏顶部的「搜索笔记」框做全文搜索，结果带命中词高亮摘要。

### 写笔记

- **标题 + 正文**：正文是所见即所得的 Markdown 编辑器（与知识库同内核），标题和内容都自动保存——右下角状态条显示「保存中… / 已保存」，保存失败会常驻红色提示。离线也能正常写，联网后自动同步。
- **附件**：标题行的「插入图片」（手机可选拍照 / 相册，也支持粘贴、拖入）和「插入附件」（任意文件，单个不超过 10MB），上传后以链接形式嵌入正文。
- **待办**：点「转为待办」把笔记变成待办事项，编辑器顶部出现完成勾选条，列表里也可直接勾选。
- **标签**：编辑器底部的标签行，点「+ 标签」多选或新建。
- **多端同步与冲突**：如果在两台设备同时编辑同一篇笔记，同步冲突时会弹出合并对话框，逐段选择保留内容（或「全部用本地 / 全部用服务端」），也可以「另存为副本」两边都留。

> [!TIP]
> 手机上编辑器顶部的 ⋮ 菜单收纳了全部操作：插入图片 / 插入附件 / 转待办 / 编辑标签 / 历史版本 / 分享 / 转入知识库 / 移入回收站。

### 历史版本

点编辑器标题行 ⋯ 菜单里的「历史版本」：左侧版本列表、右侧预览该版本的标题和正文，可以「恢复到此版本」（当前内容会先自动备份）或「另存为副本」。

### 分享笔记

1. 点编辑器标题行的「分享」按钮（或在笔记列表里右键 / 长按 → 分享），打开「分享笔记」面板。
2. 首次分享点「创建分享链接」，得到一个 `https://你的服务器/s/n/xxxx` 形式的公开链接——任何拿到链接的人无需登录即可**只读**查看这篇笔记；笔记更新后对方刷新就能看到最新内容。
3. 已创建后在同一面板里管理：

| 设置 | 选项 |
|---|---|
| 访问密码 | 开关 + 4–8 位密码，开启后打开链接需先解锁 |
| 有效期 | 1 天 / 7 天 / 30 天 / 永久 |
| 访问上限 | 不限 / 100 / 500 / 1000 / 自定义次数 |
| 重置链接 | 旧链接立即作废，换新地址（适合链接外泄时） |
| 停止分享 / 恢复分享 | 随时下线链接，之后可原地址恢复 |

面板还显示创建时间和累计访问次数，支持一键复制链接（设过密码时可复制「链接 + 密码」合并文案）和调起系统分享。左栏「已分享」视图列出所有处于分享中的笔记，点面板底部「管理全部分享 →」跳到设置里的「我的分享」管理页统一查看。

### 回收站与转入知识库

- **回收站**：中栏头部的回收站图标进入，删除的笔记按丢弃时间倒序列出，可「还原」或「彻底删除」（二次确认，永久删除不可恢复）。
- **转入知识库**：笔记写得成熟后，点 ⋯ 菜单里的「转入知识库」，选择目标知识库项目，笔记内容即归档为该项目的一个 Wiki 页面（原笔记显示「已转入知识库，此笔记已归档」提示条并从列表移除），从此参与图谱、搜索和 AI 整理。

## 网页剪藏（浏览器扩展）

BiuMind 提供浏览器剪藏扩展（Chrome / Edge / Brave），把正在浏览的网页一键收进知识库。从[官网下载页](https://biumind.ai/download)安装后，在扩展选项页填入服务器地址和登录令牌（客户端设置页里可复制）。

使用方式：

- 点工具栏扩展图标打开弹窗：选择「保存目标」（**存到知识库**——选一个项目；或**存到笔记**），确认标题（自动从页面抓取）和预览，勾选「仅保存当前选中文字」可只存划选的片段；勾选「保存后自动转成 wiki 页（CoT ingest）」后，剪藏的内容会自动走解析流程生成 Wiki 页面；
- 选中网页文字后右键 →「保存选中文字到 BiuMind」；
- 默认快捷键 `Ctrl+Shift+S`（macOS 为 `Cmd+Shift+S`）。

剪藏进知识库的网页会出现在该项目的「源文件」列表里，元信息 origin 标记为 web-clip，和其他资料一起参与解析、图谱与搜索。
