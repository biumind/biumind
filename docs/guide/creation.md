# 创作用户指南

创作是 BiuMind 的多模态生成模块：用一句提示词生成图片或视频，把一条热门短视频拆解成文案、钩子和分镜，再把结果一键变成同款素材。生成的作品统一沉淀在「我的作品」里，可以设为公开，公开后进入「创意广场」供所有人浏览和「做同款」。

入口在客户端左侧边栏的「创作」。生成需要登录并且服务器已配置创作服务；未登录时模块顶部会显示提示条，点击「登录」跳转设置页。

## 页面结构

创作模块内有四个子页面（桌面端显示为左侧导航栏，窄窗口与移动端显示为顶部横滑标签）：

| 页面 | 作用 |
|---|---|
| 灵感 | 默认首页：生成面板 + 热门公开作品推荐 |
| 中心 | 创作台：专注生成，页面下方附带「最近创作」 |
| 作品 | 我的作品：全部生成任务的瀑布流，支持批量管理 |
| 广场 | 创意广场：所有用户公开作品的瀑布流 |

模块顶部有两条状态条（正常时不显示）：

- **连接状态条**：提示登录、服务配置、网络与实时通道状态（见[连接状态与常见报错](#连接状态与常见报错)）。
- **生成进度条**：有任务在生成时显示「正在生成 · NN%」和线性进度，右侧 ✕ 可取消最新任务；任务完成、失败或退还积分时短暂显示对应提示。

## 生成图片或视频

生成面板出现在「灵感」和「中心」两个页面，结构相同：类型切换、模型选择、提示词输入、参数、参考素材、开关和提交按钮。

### 1. 选择生成类型

面板顶部有四个分段：**视频**、**图片**、**数字人**、**爆款解析**。数字人标注了「即将上线」圆点，选中后只显示预告卡片，不能提交（见[数字人（即将上线）](#数字人即将上线)）。切换类型时会保留提示词草稿，但需要重新选择模型。

### 2. 选择模型

「选择模型」chip 会按当前类型列出可用模型，每个选项显示模型名称和单价（如「N 积分」）。可用模型由服务器端模型目录决定，随部署环境不同而不同（见[可用模型说明](#可用模型说明)）；若某类型没有配置任何模型，会显示「暂无可用模型」。

选中模型后，比例、分辨率、时长等参数会自动填入该模型的默认值。

> [!TIP]
> 不同模型支持的能力不同：有的支持参考图，有的支持视频首帧 / 尾帧，有的可选时长。下面的参数行和上传行会随所选模型自动出现或隐藏。

### 3. 填写提示词

提示词输入框支持多行（3–6 行自适应），最多 2000 字。不填提示词时提交按钮不可点击。

### 4. 设置参数

参数以 chip 行展示，点击 chip 弹出选项（宽屏为紧贴下方的弹出菜单，窄屏为底部弹层）：

| 参数 | 说明 |
|---|---|
| 比例 | 画面比例（如 16:9、1:1），选项由模型决定 |
| 分辨率 | 如 720P，选项由模型决定 |
| 时长 | 仅视频模型支持，按模型给定的档位（如 5 / 10 / 15 秒） |
| 数量 | 固定 1 / 2 / 4 张，多输出作品在卡片上以 +N 角标提示 |

### 5. 首帧 / 尾帧 / 参考图

如果所选模型声明支持，参数行下方会出现对应入口：

- **首帧** / **尾帧**：单图，用于控制视频的起止画面。
- **参考图**：多图（上限由模型决定，默认 5 张），用于图像风格参考。

> [!NOTE]
> 当前版本粘贴的是图片地址（`cas:<sha>` 或 `https://…` 链接），对话框内也有「文件上传将在下一版接入」的提示。本地文件选择与上传尚不可用。

### 6. AI 优化与共享作品

提交行上方有两个开关：

- **AI 优化**：开启后请求会附带提示词优化标记，由服务端优化提示词。
- **共享作品**：开启后该作品提交时即标记为公开，出现在创意广场。默认关闭；也可以之后在「我的作品」里随时切换（见[公开与私有](#公开与私有)）。

### 7. 提交与计费

提交按钮左侧实时显示所选模型的报价（「N 积分/条」）。点击「生成」后：

1. 「我的作品」和「中心」下方的最近创作中立即出现一张「待处理」占位卡。
2. 提交成功即扣费，侧边栏积分余额立即刷新，提示词清空、参数保留，方便连续创作。
3. 提交失败（如积分不足）会弹出具体原因的提示条，占位卡移除，不扣费。

### 8. 跟踪进度与取消

生成是异步任务，进度实时推送：

- 卡片上显示状态文字（待处理 → 排队中 → 生成中）和进度百分比进度条。
- 模块顶部的进度条在多任务并行时显示「N 个生成中… (最新 NN%)」。
- 排队中 / 生成中的卡片右下角有 ✕ 按钮，可取消该任务；顶部进度条的 ✕ 取消最新一个任务。
- 任务完成时顶部弹出「生成完成」提示；失败时弹出失败原因；被拦截的审核任务显示「内容审核未通过」。
- 即便离开创作页面去别的模块，任务照常执行；任务列表在本地持久化，重启客户端后仍能看到最近的作品。

> [!TIP]
> 关闭客户端也不影响服务端继续执行任务——重新打开后回到「我的作品」即可看到结果。

## 爆款解析

爆款解析把一条热门短视频自动拆解成可复用的创作素材。

### 提交链接

切到「爆款解析」类型后，输入框变为链接输入：粘贴 B 站 / 抖音分享链接，或公网视频直链（mp4 / m3u8）。解析不需要提示词，只填链接即可提交，提交按钮为「开始解析」。界面提示小红书解析即将上线。

### 查看拆解结果

解析完成后，在「我的作品」点开该任务（或在详情底部弹层中查看），结果分为五个部分：

| 部分 | 内容 |
|---|---|
| 文案 | 全文拆解出的口播文案，可一键复制 |
| 钩子 | 开头抓人的钩子要点列表 |
| 分镜 (N) | 逐条分镜：编号、画面描述、可直接用于生成的提示词 |
| 标签 | 话题标签（# 开头） |
| 转写全文 | 视频语音转写，可展开、可复制 |

解析仍在进行时显示「正在解析视频…」；失败时显示具体原因。

### 生成同款

每个分镜右侧有「生成同款」按钮，把该分镜的提示词直接发起一次图片生成（自动选用列表中第一个可用图像模型）；分镜区标题行还有「一键全部同款」，为全部分镜各发起一次生成。同款生成会记录与原解析任务的血缘关系，方便追溯素材来源。如果当前没有任何可用图像模型，会改为把分镜提示词预填到创作台，由你选好模型后再生成。

## 我的作品

「我的作品」展示你的全部生成任务（含图片、视频、爆款解析），按创建时间倒序排列成瀑布流。桌面端每行 2–6 张，视窗口宽度自适应。

### 卡片状态

| 状态 | 卡片表现 |
|---|---|
| 待处理 / 排队中 / 生成中 | 渐变占位 + 状态文字 + 进度条，可取消 |
| 已完成 | 成品图（视频显示封面和播放图标）；鼠标悬停浮出提示词摘要与「做同款」「删除」按钮；多输出显示 +N 角标 |
| 生成失败 | 错误说明 + 「重新生成」「删除」按钮；如有退款会显示「已退还 N 积分」 |
| 内容审核未通过 | 盾牌图标 + 说明 |
| 已取消 | 说明文字 + 「删除」 |

### 查看详情

单击卡片打开底部详情弹层：大图预览（多输出时下方有缩略图行）、完整提示词、负向提示词（如有）、模型、类型、参数、实际消耗积分与退款积分。爆款解析任务在弹层中直接展示拆解结果。

### 做同款与重新生成

- **做同款**：把作品的类型、模型、提示词和参数原样回填到创作台，可直接提交，也可先修改。
- **重新生成**（仅失败任务）：与做同款一样把参数填回创作台，改好后重新提交。

### 公开与私有

作品默认私有。两种切换方式：

- 详情弹层右上角的锁 / 地球按钮，在公开与私有间切换。
- 批量模式下一键切换多件作品（见下）。

公开的作品会出现在创意广场，其他用户能看到提示词与参数并发起做同款。

### 批量管理

点顶部工具条的「选择」（或在卡片上**长按**）进入多选模式：卡片左上角出现勾选圆点，工具条变为「已选 N」+「全选」「公开」「私有」「删除」「退出」。选中后点对应按钮即批量执行。

### 删除

删除入口有三处：卡片悬停浮层的删除按钮、详情弹层的删除按钮、批量模式的删除按钮。删除后作品立即从列表消失，广场同步不再展示。

> [!WARNING]
> 删除不可撤销。多输出作品删除时会整组一起删除。

## 创意广场

创意广场汇集所有用户的公开作品：

- **类型过滤**：全部 / 图片 / 视频 / 数字人。
- **关键词搜索**：输入关键词后回车，按提示词等字段过滤。
- 点任意卡片打开详情弹层，可查看完整提示词与参数并发起「做同款」——别人的作品只有做同款，没有公开 / 删除按钮。

广场为空时提示「广场暂无公开作品」，并附「去创作」按钮跳转创作台。

## 创作灵感

「灵感」是创作模块的默认首页：顶部是「创作」大标题与副标题，中间是完整的生成面板，下方「热门作品」横向展示 12 件公开作品，点「更多」进入创意广场。这里适合逛一逛找灵感，看到合适的直接做同款。

## 数字人（即将上线）

数字人生成（上传形象 + 选择音色，一键生成口播数字人视频）尚未开放：客户端选中该类型时只显示「数字人合成 · 即将上线」的预告卡片，服务端也对该类型直接拒绝，目前无法提交。

> [!NOTE]
> 代码中已包含数字人角色选择器（内置角色 + 自建角色 + 音色选择、新建角色表单）的实现，但因生成链路未开放，当前版本里没有任何入口能打开它。待功能上线后本节将补充完整操作说明。

## 积分与消耗

### 余额在哪看

登录后，客户端主侧边栏底部常驻一个积分徽标：闪电图标 + 当前积分数字（侧边栏收窄时只显示缩写数字，如 1.2k）。鼠标悬停可看到余额与本月对话额度进度；点击进入**会员中心**，那里同时是充值入口。

### 生成怎么扣费

- 提交生成前，提交按钮左侧按所选模型显示单价「N 积分/条」。
- 提交成功即扣费（不是等生成完成才扣），余额即时刷新。
- 每件作品的实际消耗记录在详情弹层的「消耗」一栏。

### 失败退还

任务失败或被取消时，已扣积分自动退还：卡片上显示「已退还 N 积分」，模块顶部也会弹出退还提示，余额同步刷新。详情弹层的「退款」一栏可查累计退还数额。

### 充值

积分不足时提交会直接失败并提示「积分不足， 请先充值」。点击侧边栏积分徽标进入会员中心即可查看充值套餐并购买。

## 连接状态与常见报错

模块顶部的状态条只在异常时出现：

| 提示 | 含义 | 处理 |
|---|---|---|
| 未配置 AIGC 服务地址 — 创作功能不可用 | 已登录但服务器没配创作服务 | 点「去设置」完成配置 |
| 登录后即可创作 / 查看作品 | 未登录 | 点「登录」 |
| 实时通道断开, 30s 轮询兜底中 — 进度可能略有延迟 | 实时推送断线，已自动切换为 30 秒轮询 | 无需处理，恢复后自动切回 |
| 网络异常 — 作品列表可能不是最新 | 网络不可用 | 检查网络，恢复后自动同步 |

常见报错提示：积分不足请先充值、所选模型与类型不匹配请重新选择（切换类型后未重选模型时出现）、该模型已下架、内容触发审核请修改提示词、调用过于频繁请稍后再试等。所有错误都以中文提示条展示，不会出现技术细节。

## 可用模型说明

创作面板里的模型列表来自服务端模型目录，按「图片 / 视频 / 爆款解析」类型分别提供，每个模型带显示名称与积分单价。哪些模型可用由所在环境的管理员在管理后台配置，因此云端 SaaS 与不同自托管实例的模型清单可能不同；默认开箱可用的只有「爆款解析」。如果某个类型下没有模型，说明该环境尚未接入对应的上游服务，请联系管理员。数字人生成当前未开放。
