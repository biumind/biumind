# 应用中心指南

应用中心是 BiuMind 的应用目录：在这里浏览、安装、升级和管理应用，把常用的固定到侧边栏，或者把任意网站和开源项目变成工作台里的一员。

入口在桌面客户端左侧边栏的「应用中心」。使用前需要先在「设置」中登录并配置服务器凭据，否则应用中心只会显示占位提示，不会加载目录。

## 浏览与查找应用

打开应用中心后是一个应用卡片网格（窗口越宽每行越多，手机上为两列）。每个卡片显示应用图标、名称、简介，已安装的应用带「已安装」徽章。

页面顶部提供两种筛选方式：

- **搜索框**：按名称、标识符或简介模糊匹配，输入即时过滤。
- **分类标签**：`全部` / `已安装 (n)` / `生产力` / `内容` / `数据` / `沟通` / `开发者` / `工具`。

点击任意卡片进入该应用的详情页。在卡片上**右键**（触屏长按）会弹出快捷菜单：

| 菜单项 | 作用 |
|---|---|
| 固定到侧边栏 / 取消固定 | 把已安装的应用钉进左侧边栏（未安装时该项置灰，提示先安装） |
| 自定义侧边栏… | 打开[侧边栏定制](#定制侧边栏)页面 |

标题栏右侧还有四个按钮：**添加 WebView 应用**（+ 链接图标）、**安装 GitHub 应用**（下载图标，仅桌面端显示）、**刷新**、**管理**（进入应用管理页）。

> [!TIP]
> 如果本地正在用 CLI 跑 `biu app run --dev` 调试自己的应用，目录顶部会出现一个「开发中」区块，其中的卡片带 `DEV` 徽章，与正式安装的应用明确区分。普通使用时看不到这个区块。

## 查看应用详情

详情页头部是应用大图标、名称、作者与版本，右侧为操作按钮区。往下依次展示：

- **完整描述**
- **权限**：该应用声明的所有权限，以标签形式列出；其中访问外部网络、沙盒执行、读取凭据这类高权限会用醒目的警示样式标出
- **视图**（如有）：应用自带哪些界面
- **触发器**（如有）：定时（cron）/ webhook 等自动触发方式
- **附带技能**（如有）：安装该应用同时会装入的 Skills

操作按钮随安装状态变化：

- **未安装**：显示「安装」主按钮
- **已安装**：显示「打开」（进入应用界面）、启用/停用开关、「卸载」

纯后台运行的应用（没有声明视图）不显示「打开」按钮——它的能力通过对话中的技能体现，装完留在详情页阅读说明即可。

## 安装应用与权限确认

点击「安装」后弹出权限确认对话框：

1. 列出应用声明的每项权限，每项前有说明文字（例如「访问指定外部网络。仅限 manifest 列出的域名」「读取你 Wiki 中的内容」）
2. 所有权限默认勾选；**你可以取消勾选任何权限**，应用安装后在运行时就不会拥有被取消的权限
3. 高风险权限带警示图标，安装前请逐项确认
4. 点「安装」完成；点「取消」放弃

安装成功后会弹出提示条。如果应用带有界面，会**自动进入应用主界面**，省去装完找入口的麻烦；提示条上还会附带「添加到侧边栏」按钮（每个应用 7 天内最多提示一次），点击即可固定到侧边栏。

> [!NOTE]
> WebView 类应用卸载时会同时清掉该站点在客户端里的登录 Cookie 等数据，重新安装同一站点相当于全新登录。

## 管理与升级已安装的应用

点击应用中心标题栏的「管理」进入**应用管理**页：

- **可用升级区**：有新版本的应用集中列在这里，每行带「升级」按钮和 `v当前 → v目标` 版本号
- **已安装列表**：每行显示应用名、版本、归属范围，右侧依次是「打开」、启用/停用开关、「卸载」按钮；点行进入详情页

**升级流程**：点「升级」后弹出权限差异对话框，分三段展示（只显示有内容的部分）：

| 分段 | 含义 | 需要你做什么 |
|---|---|---|
| 新增权限（红） | 新版本会多出的权限 | **逐项勾选确认**，全部勾选后「升级」按钮才可用 |
| 不再请求（灰） | 新版本不再使用的权限 | 仅告知，无需操作 |
| 已授予 | 维持不变的权限 | 默认折叠，可展开查看 |

点「暂不升级」保持当前版本。如果本次升级不涉及新权限，对话框会直接提示可一键升级。

> [!WARNING]
> 组织管理员强制安装的应用在管理页不能停用或卸载（按钮置灰），需要联系管理员处理。

## 添加 WebView 应用

想把常用网站收进 BiuMind？点标题栏的**添加 WebView 应用**按钮，填两三项即可：

1. **名称**：显示在应用中心和侧边栏的名字（例如「Kimi」）
2. **URL**：只支持 http(s)，必须是完整域名或 localhost
3. **图标**：不用填——输入 URL 后客户端会自动抓取该站点的 favicon 并预览；不满意可以改 URL 重新触发抓取

创建成功后自动跳到该应用的详情页，之后可以像普通应用一样打开使用、固定到侧边栏。

> [!NOTE]
> 所有 WebView 应用共享一份登录态：在 BiuMind 内登录某网站后，所有 WebView 应用看到的 Cookie 一致，且与系统浏览器互相隔离。需要多账号时请使用系统浏览器。

WebView 应用界面带一条浏览器工具栏（前进 / 后退 / 刷新等）。跳转到**其他网站**时会先弹确认框防止钓鱼跳转；仅允许 http(s) 地址。Windows / Linux 及网页版客户端没有内嵌 WebView 引擎，会显示「在外部打开」和复制链接的降级界面。

## 安装 GitHub 仓库应用

（仅 macOS / Linux 客户端；需要本机安装 biu CLI）

应用中心支持把 GitHub 上的开源项目一键变成**本地运行的 Web 应用**：客户端在本机克隆仓库、安装依赖、启动服务，再把它的 Web 界面接进工作台。

操作流程：

1. 点标题栏的**安装 GitHub 应用**按钮，粘贴仓库地址（如 `https://github.com/owner/repo`），点「分析仓库」
2. 分析完成后显示确认页：
   - **分析摘要**：项目名、版本、Stars、许可证、描述，以及分析过程中的警告（如有）
   - **将在本机执行**：技术栈、安装依赖命令、启动命令、端口、健康检查、需要的运行时（缺失时是否自动安装）——执行前看得清清楚楚
   - **配置**：项目需要的环境变量表单；机密字段旁标「🔒 仅存本机，不上传服务器」
   - **版本来源**：选择跟随「最新 Release」还是「默认分支」
3. 点「安装」。首次打开时客户端会克隆仓库并安装依赖（可能需要几分钟，界面实时显示进度日志），完成后：

   - **macOS**：应用在独立原生窗口中打开；关闭窗口不影响后台服务，下次打开秒连
   - **Linux**：在应用内全屏运行；启动失败可一键重试

不支持的仓库类型会在分析阶段直接给出原因。**升级**走应用管理页：GitHub 应用的升级按钮执行「确认 → 服务端重新构建 → 本机更新（失败自动回退旧版本）」，不弹权限差异框。

> [!WARNING]
> GitHub 应用会在你本机执行仓库里的代码。只安装你信任的仓库，仔细阅读「将在本机执行」里的命令列表后再确认。

## 应用的界面形态

安装后点「打开」，应用界面由两种方式呈现：

- **声明式视图**：由应用清单描述、客户端原生渲染的界面。常见形态有列表、列表-详情、表单、网格、仪表盘、对话式等；界面上的工具栏按钮和刷新都由应用自定义。
- **动态界面**：应用在运行时下发一套界面描述树（文字、卡片、按钮、输入框、图表等组件的嵌套组合），客户端按白名单渲染。好处是应用可以灵活变更界面内容，同时客户端对组件数量和嵌套深度有硬性上限，异常庞大的界面树会被拒绝渲染。
- **WebView 面板**：整个界面就是内嵌网页（见上一节）。

## 定制侧边栏

侧边栏决定了哪些入口常驻手边。进入「侧边栏定制」页有三条路：

- 侧边栏底部的调节（tune）图标按钮
- 应用卡片右键菜单 →「自定义侧边栏…」
- 直接把应用中心的卡片**拖到侧边栏**上（松手即固定）

页面分三段：

| 区块 | 能做什么 |
|---|---|
| 系统（控制是否显示） | Chat、搜索、Wiki、笔记、Skills、应用中心、Code 等系统入口：可拖动排序、勾选控制是否显示（系统入口只能隐藏，不能删除） |
| 已固定的应用 | 已钉入侧边栏的应用：拖动排序、点 × 移除；若某应用已卸载会显示为无效项，建议移除 |
| 可固定的应用 | 已安装但未固定的应用：点「固定」加入侧边栏 |

改完点右上角「保存」；「恢复默认」一键还原。保存会同步到云端，**所有设备的侧边栏保持一致**：

- 另一台设备刚改过侧边栏时，本机编辑页会提示「另一设备已改动侧边栏，已重新载入最新版本」
- 断网时编辑会暂存本地（顶部出现黄色提示条），重连后自动同步

侧边栏本身还支持收起 / 只显示图标 / 显示图标和文字三种模式。

## 内置应用

当前版本应用中心实际提供三个内置应用：

### RSS 订阅

一站式信息中枢，安装后从详情页「打开」进入，共六个标签页：

- **Today**：AI 每日精选头条——大标题卡 + 要闻网格 + 错过榜 + 趋势条；右上角可「重新生成」，还能把当日简报**合成成语音播放**（播放/暂停/进度都有）
- **收件箱**：经典三栏阅读器（订阅源列表 | 文章列表 | 阅读器），窄屏自动折叠。点「订阅」添加新源，支持三种来源：
  - RSS / 网站：粘贴地址，服务端自动发现订阅源
  - 公众号：输入公众号名称（需先在 RSS 设置里配置公众号中继地址）
  - X 用户：输入 @handle（需先在设置里配置 Nitter 实例地址）
  收件箱右上角「刷新所有订阅」手动拉取（快捷键 `R`），也可在设置里配置 15 分钟 ~ 3 小时的自动刷新频率
- **雷达**：监控规则引擎。左栏规则列表（可启停），右栏命中结果（可按全部 / 未读筛选）。点「新规则」用可视化编辑器创建：关键词（任一命中 / 全部命中 / 排除）、来源范围、严重级别、冷却时间，还可以先用**自然语言描述再点「AI 解析」**自动生成规则。每条规则可配「动作配方」：命中后发通知、沉淀到 Wiki、创建任务或调用技能
- **榜单**：各平台热点榜单卡片墙（热点、趋势、社区等），点击条目跳转原文
- **探索**：一键订阅精选「主题包」，或从 Feedly / Inoreader 等导出的 **OPML 文件全量迁移**订阅
- **已收藏**：你标记过的内容分四类回看——收藏 / 已沉 Wiki / 钉住 / 已分享

右上角还有两个高频功能：

- **AI Co-Pilot**（快捷键 `⌘J` / `Ctrl+J`）：右侧抽屉里针对当前视图（Today / 收件箱 / 雷达）提问，回答带引用角标，点击引用跳转原文
- **分享此视图**：把今日要闻 / 订阅 / 雷达命中 / 收藏生成一个**只读分享链接**，复制发给没装 BiuMind 的人也能看

「⋯」菜单里是**设置**：主题（深色模式下阅读器自动启用真黑）、默认刷新频率、AI 摘要开关（为新文章生成 AI 摘要，消耗积分）、公众号 / Nitter 中继配置、导出 OPML、导出全部数据（订阅 / 文章 / 收藏 / 规则 / 设置打包成 zip）。

> [!TIP]
> 团队版用户在应用栏下方可切换「我的 / 团队」数据范围：切到团队后，订阅源、雷达规则与命中按团队共享。

### 翻译

调用平台模型把文本翻译成目标语言的小工具，源语言可选「自动检测」。

### 任务

个人任务清单：创建任务、按完成状态 / 标签筛选、标记完成、删除。

## 已知边界

- 当前服务端实际注册的应用只有 **RSS 订阅**、**翻译**、**任务**三个；目录中的其他卡片取决于你连接的服务端部署了哪些应用
- GitHub 仓库应用目前仅支持 macOS / Linux 客户端，Windows 与移动端会显示平台不支持说明
- 想开发自己的应用接入应用中心，见开发者文档 [BiuApp 开发指南](../developers/biuapp.md)
